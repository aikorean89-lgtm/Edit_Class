# Edit Class

초등학교 담임교사를 위한 학급관리 웹앱입니다. 서버 없이 동작하는 단일 HTML 파일로, 브라우저에서 바로 열어 사용할 수 있습니다.

## 사용 방법

1. `index.html` 파일을 다운로드합니다.
2. 브라우저(크롬, 엣지 등)에서 파일을 엽니다.
3. 교사 계정으로 회원가입하고 학교/학급 정보를 설정합니다.

## 주요 기능

- 우리 반 관리: 학생 명단(엑셀 가져오기 포함), 출결, 관찰기록, 포인트/쿠폰, 교우관계 분석, 자리배치(드래그앤드롭), 출석 통계, 수행평가·성적, 학급 사진첩
- 학습 코너: AI 어린이 뉴스, 학생 일기, 급식·영양(알레르기 정보 포함)
- 수업 도구: 화면 공유 수업 진행, 글자 수 카운터, 교육 경력 계산기, 랜덤 뽑기, 타이머, 미니 로또
- 학교 업무: 특별실/기자재 예약, 업무 게시판·교무회의·업무분장, 결보강 관리, 취합 — 같은 학교 교사 간 공유 가능
- 학생 전용 화면: 학급 코드로 가입해 기분 체크, 할일, 포인트 확인, 일기 작성, 실시간 수업 화면 시청
- AI 비서: 채팅 및 가정통신문 초안 생성

## 참고

- 데이터 저장은 Claude 아티팩트 환경의 저장소 기능을 사용하며, 해당 환경 밖에서는 세션 내에서만 유지됩니다.
- 이 프로젝트는 Claude(Anthropic)와의 대화를 통해 개발되었습니다.
